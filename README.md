Square Auth — Advanced Script Protection

Square Auth is an advanced script authentication and protection system designed for developers who want to protect, manage, and distribute their scripts.

Inspired by the script protection ecosystem, Square Auth offers Luraph obfuscation, a protected loader, authentication tools, custom Discord bots, and personalized subdomains.

🛡️ Protection Features

- Anti-Deobfuscation: Protection mechanisms designed to make reverse engineering more difficult.
- Luraph Obfuscation: Script obfuscation powered by Luraph.
- Protected Loader: A protected loader for authenticated script execution.
- Authentication System: Manage access to your scripts.
- Unlimited Obfuscation: Unlimited obfuscation usage included in the cheapest plan.
- No Anti-Ban Protection: Square Auth does not provide protection against game bans.

💳 Discord-Only Purchases

All Square Auth plans are purchased exclusively through the official Discord server. There is no separate website checkout for purchasing subscriptions.

After purchasing a plan, the customer receives access to the Square Auth system and can configure their own Discord bot.

🤖 Create Your Own Discord Bot

After purchasing a subscription:

1. Open the Discord Developer Portal.
2. Create your own Discord application and bot.
3. Customize the bot's name, profile picture, and other supported appearance settings.
4. Copy the bot token and configure it in Square Auth.
5. Invite the bot to your Discord server and use the available Square Auth commands.

The bot is built with JavaScript, and developers use their own bot to interact with the system.

🌐 Custom Subdomains

Each eligible plan includes a custom subdomain. Customers can choose between two domain options:

- "myurl.SquareAuth.gg"
- "myurl.MyAuth.dev"

The chosen subdomain provides a personalized address for the developer's authentication setup.

📅 Subscription Duration

All plans last for 30 days.

- Days 1–30: The subscription remains active.
- Days 31–37: A seven-day grace period allows the customer to renew.
- After the grace period: If the subscription has not been renewed, the customer's bot integration and subdomain are deactivated.

Subscriptions are managed through Discord, not through a website checkout.

⚙️ Script Control

Script deactivation is separate from subscription expiration.

If a developer manually disables or removes a script, users attempting to execute it will be denied authorization. The system can also be configured to kick the relevant user from the associated Discord server when they attempt to execute a disabled script.
